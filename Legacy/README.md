# Legacy (non-production)

`McpServer/` and `GodotPlugin/` are archived reference implementations from earlier releases; old HTTP test files use the fixed 7777 port. **They are not part of the v3 solution, not started by any current script, and should not be installed.**

Use [C# RuntimeHost](../RuntimeHost/) and [Godot addon](../addons/godot_mcp/) instead. The new architecture is documented in [README](../README.md).
